# SmoothContacts

![SmoothContacts](https://raw.githubusercontent.com/MarkN2000/SmoothContacts/main/icon.png)

A [Resonite](https://resonite.com/) mod that reduces freezing when opening Contacts or clearing a search.

Adjust the batch size and update interval in Bepis Mod Settings. Default: **5 contacts per batch, with 1 update skipped between batches**.
