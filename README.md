# SmoothContacts

[![Thunderstore Badge](https://modding.resonite.net/assets/available-on-thunderstore.svg)](https://thunderstore.io/c/resonite/)

![SmoothContacts](https://raw.githubusercontent.com/MarkN2000/SmoothContacts/main/icon.png)

A [Resonite](https://resonite.com/) mod that reduces freezing when opening Contacts or clearing a search.

Adjust the batch size and update interval in Bepis Mod Settings. Default: **5 contacts per batch, with 1 update skipped between batches**.

## Installation

1. Install [BepisLoader](https://thunderstore.io/c/resonite/p/ResoniteModding/BepisLoader/).
2. Install via a Thunderstore mod manager or download from [Releases](https://github.com/MarkN2000/SmoothContacts/releases).
